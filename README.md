# 🛒 Smart Retail Analytics & Intelligence System

An AI-powered retail analytics application designed to help businesses analyze sales transactions, forecast future demand, understand customer behavior, and optimize inventory management.

## 🚀 Project Overview

This project uses machine learning and data analytics to transform retail transaction data into actionable business insights through an interactive Streamlit dashboard.

## ✨ Key Features

- 📊 Retail Sales Analysis and Visualization
- 📈 Sales Forecasting using Machine Learning
- 🛍️ Customer Segmentation
- 📦 Inventory Management and Stock Recommendations
- 📉 Business Performance Analytics
- 📁 CSV Dataset Upload and Processing
- 🖥️ Interactive Streamlit Dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas & NumPy
- Plotly & Matplotlib
- Scikit-learn
- Machine Learning
- CSV Data Processing

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Pawan680-u/smart-retail-analytics.git
cd smart-retail-analytics
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

Open the application at:

http://localhost:8501
